# 导师工作区契约

## 本次实现
- 今日页与岗位页右侧导师对话；岗位页原待办折叠。
- 云端 `coach_agent_turns` 按 user_id + opportunity_id 隔离；个人背景走既有 Context Compiler，当前岗位材料每次重新读取，旧回答不作为确认事实。
- 回显最近 12 轮；模型只读取最近 4 轮截断对话。上下文主体 6000 token 预算，回答 1200 token；普通对话没有工具 loop。
- 私有接口 `private, no-store`，不跨用户缓存答案；公开就业来源使用独立共享表缓存，20 小时去重，48 小时过期不引用。
- Vercel Cron 每日 UTC 01:00；常量时间校验 CRON_SECRET，缺配置拒绝请求。仅固定 HTTPS 官方站点、不跟随重定向、12 秒超时、600 KB 上限，拒绝验证码/阻断页。
- 市场材料只在相关问题里注入，标明地区、来源、抓取时间不是发布时间；目录页不支持具体统计结论。当前仅国家统计局发布目录和美国 BLS 就业报告，不代表全面岗位调研。

## 尚未实现，不能宣称完成
- 这不是 OS/容器执行沙箱。模型没有命令执行、浏览器、网络工具、外发消息或投递权限；用户与岗位隔离是数据作用域，不等于进程隔离。
- 真正执行沙箱需补：供应商与费用上限、用户/任务所有权校验、启动/暂停/销毁、闲置 TTL、并发和资源配额、文件路径边界、出网白名单、审批与审计。
- 未引入自动长期摘要和可编辑记忆面板；长期背景依赖既有事实/简历/产物，聊天只加载短窗口，不假称记住全部聊天。
- 心跳当前更新证据，不主动给用户生成招聘结论或推送通知；首次定时运行与真实来源提取需单独验收。
- 没有显式 provider KV/prompt cache 命中观测，不用本地指纹冒充模型缓存命中。

## 验收
- 未登录 401；非法 scope 400；查询必须带 owner 和岗位/null 条件。
- 切岗位卸载旧会话，迟到响应不能写进新窗口；刷新读取云端已保存对话。
- LLM/数据库失败不得显示已保存，不替用户执行后续动作。
- 只计成功生成额度；授权和 TokenPay 恢复沿用现有 metered wrapper。
