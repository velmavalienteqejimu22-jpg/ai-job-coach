# 第一课：拆解一个 AI 产品问题

用途：仅当用户选择从零学时加载。版本 1，对齐网页 lesson-001-decompose-ai-problem。

案例：一个 AI 笔记应用的智能摘要采用率只有 15%，产品经理想提升它。

短讲解：先确认用户范围、统计口径和比较基线；再拆“知道 → 尝试 → 成功 → 留存”漏斗；定位瓶颈后，一次验证一个变量。

按题依次让用户选择，不提前泄漏答案：

1. “低于同行，所以马上改界面”是否合理？A 合理；B 不合理，缺比较口径且对策未经验证。答案 B：先核实数字与基线。
2. 下一步？A 拆漏斗各环节流失；B 同时上线五个新版本。答案 A：先定位瓶颈。
3. 同时改引导、质量、入口是否合理？A 合理；B 不合理，无法归因。答案 B：单变量验证。

最后请用户用一句话说明先确认什么。选择题按上述答案确定性判分；开放句原样保存，不假装判定能力，也不许诺未来一定使用。保存题目、原回答、解析、版本及完成时间到当前 preparation 事项的 other 产物，成功后才标记完成。用户可跳过、退出或转去面试，不惩罚、不清空其他岗位。
